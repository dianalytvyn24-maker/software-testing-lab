Тест вебсайту: https://www.kopiyochka.ua/

Створено скрипт автоматизованого тестування вебсайту «Копійочка» за допомогою JavaScript та Playwright.

Автоматизовані перевірки

1. Перевірка завантаження сайту. Перевіряє, чи успішно відкривається вебсайт і чи сервер повертає успішну HTTP-відповідь.
2. Перевірка заголовка сторінки. Перевіряє, чи має вебсторінка непорожній заголовок.
3. Перевірка вмісту сторінки. Перевіряє, чи відображається текстовий вміст вебсторінки.

Інструкція із запуску тесту
   
1. Встановити Node.js.
2. Створити файл командою npm.cmd init -y
3. Встановити Playwright командою:
npm.cmd install -D @playwright/test
4. Встановити браузери командою:
npx.cmd playwright install
5. Запустити тест командою:
npx.cmd playwright test kopiyochka.spec.js --headed
